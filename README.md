## 1. 프로젝트 소개

Re:hear는 발표를 준비하는 사용자가 발표 훈련 계획을 생성하고 관리할 수 있도록 제작한 웹 프로토타입입니다.

사용자는 발표 제목, 발표자 이름, 훈련 시간, 질의응답 여부 등의 조건을 설정하고, 완성한 계획을 브라우저에 저장할 수 있습니다.

저장한 계획은 다시 확인하거나 필요하지 않을 경우 취소할 수 있습니다.

본 프로젝트는 수업용 프로토타입으로 실제 녹음 및 발표 훈련 기능은 제공하지 않습니다.

## 2. 사용자와 목표

**사용자**
- 발표를 준비하는 학생 및 일반 사용자
- 발표 연습 계획을 체계적으로 관리하고 싶은 사람

**목표**
- 발표 제목과 훈련 조건을 설정한다.
- 입력값을 검증하고 오류 메시지를 확인한다.
- 설정한 훈련 계획을 최종 확인하고 저장한다.
- 저장한 계획을 다시 조회하거나 취소한다.
- 브라우저를 새로고침해도 저장한 계획을 유지한다.

## 3. 사용자의 흐름

1. Re:hear 웹사이트에 접속한다.
2. '새 훈련 계획 만들기' 버튼을 클릭한다.
3. 발표 제목과 발표자 이름을 입력한다.
4. '훈련 조건 선택하기' 버튼을 클릭한다.
5. 발표 시간과 질의응답 포함 여부를 선택한다.
6. '내용 확인하기' 버튼을 클릭한다.
7. 입력한 발표 정보와 훈련 조건을 확인한다.
8. 필요한 경우 이전 단계로 돌아가 내용을 수정한다.
9. '계획 저장하기' 버튼을 눌러 훈련 계획을 저장한다.
10. '내 계획'에서 저장한 계획을 확인하거나 취소한다.

## 4. 인터랙션 시나리오

### 4-1. 발표 정보 입력

**행동 및 이벤트**
- 발표 제목과 발표자 이름을 입력한다.
- '훈련 조건 선택하기' 버튼을 클릭한다.

**조건**
- 발표 제목이 2자 이상 60자 이하인가?
- 앞뒤 공백을 제거한 제목이 유효한가?
- 발표자 이름은 선택 입력이며 최대 10자인가?

**반응 및 다음 상태**
- 제목이 유효하지 않으면 오류 메시지를 표시한다.
- 오류가 있는 입력창에 초점(Focus)을 이동한다.
- 제목 글자 수를 실시간으로 표시한다.
- 유효한 값이면 다음 단계로 이동한다.

### 4-2. 훈련 조건 선택

**행동 및 이벤트**
- 발표 시간을 선택한다.
- 질의응답 포함 여부를 선택한다.
- '내용 확인하기' 버튼을 클릭한다.

**조건**
- 사용자가 선택한 훈련 시간이 무엇인가?
- 질의응답을 포함하도록 설정했는가?

**반응 및 다음 상태**
- 선택한 훈련 시간을 화면에 표시한다.
- 질의응답 포함 여부에 따라 관련 설정을 표시한다.
- 선택한 정보를 유지하면서 내용 확인 단계로 이동한다.

### 4-3. 훈련 계획 내용 확인

**행동 및 이벤트**
- 발표 제목, 발표자 이름, 훈련 시간, 질의응답 설정을 확인한다.
- 이전 단계로 이동하거나 계획 저장을 진행한다.

**조건**
- 사용자가 내용을 수정하려는가?
- 사용자가 계획 저장을 요청했는가?

**반응 및 다음 상태**
- 이전 단계로 돌아가도 입력한 값은 유지된다.
- 저장 요청 시 중복 제출을 방지하도록 저장 버튼 상태를 관리한다.
- 저장 처리 상태를 사용자에게 안내한다.

### 4-4. 훈련 계획 저장

**행동 및 이벤트**
- '계획 저장하기' 버튼을 클릭한다.

**조건**
- 필수 입력값이 유효한가?
- 저장 처리가 진행 중인가?

**반응 및 다음 상태**
- 유효한 계획 정보를 브라우저의 로컬 스토리지(Local Storage)에 저장한다.
- 저장 완료 상태를 안내한다.
- 저장한 계획을 '내 계획' 영역에서 확인할 수 있도록 한다.
- 서버나 외부 데이터베이스에는 저장하지 않는다.

### 4-5. 저장한 계획 조회 및 취소

**행동 및 이벤트**
- '내 계획' 영역으로 이동한다.
- 저장된 계획을 확인한다.
- 필요하지 않은 계획을 취소한다.

**조건**
- 저장된 계획이 존재하는가?
- 사용자가 계획 취소를 요청했는가?

**반응 및 다음 상태**
- 저장된 계획이 없으면 빈 목록 안내 메시지를 표시한다.
- 저장된 계획이 있으면 목록에 표시한다.
- 계획을 취소하면 저장 목록과 화면에 변경 사항을 반영한다.
- 새로고침 후에도 저장된 계획을 유지한다.

## 5. 주요 구현 기능

| 기능 | 구현 내용 |
|---|---|
| 발표 정보 입력 | 발표 제목 및 발표자 이름 입력 |
| 입력값 검증 | 필수 입력, 글자 수 제한, 오류 메시지 |
| 실시간 글자 수 | 입력한 글자 수 표시 |
| 단계별 화면 | 발표 정보 → 훈련 조건 → 내용 확인 |
| 훈련 조건 | 발표 시간 및 질의응답 여부 선택 |
| 이전 단계 이동 | 입력값을 유지하면서 수정 |
| 계획 저장 | Local Storage를 이용한 브라우저 저장 |
| 계획 조회 | 저장된 발표 훈련 계획 목록 표시 |
| 계획 취소 | 저장된 계획 삭제 및 목록 갱신 |
| 저장 상태 안내 | 저장 진행 및 완료 상태 표시 |
| 다크 모드 | 사용자 화면 테마 전환 |
| 반응형 화면 | 다양한 화면 크기에 대응 |

## 6. 사용 기술

- HTML5: 웹페이지 구조 작성
- CSS3: 화면 디자인 및 반응형 레이아웃
- JavaScript: 사용자 이벤트와 인터랙션 구현
- DOM(Document Object Model): 입력값 및 화면 상태 제어
- Local Storage: 브라우저 내 훈련 계획 저장
- Git / GitHub: 소스코드 버전 관리
- GitHub Pages: 정적 웹사이트 배포

## 8. 프로젝트 제한 사항

- 실제 발표 녹음 기능은 제공하지 않습니다.
- 실제 발표 분석 및 AI 피드백 기능은 제공하지 않습니다.
- 훈련 계획은 현재 브라우저에만 저장됩니다.
- 다른 브라우저나 기기와 저장 데이터를 동기화하지 않습니다.
- 브라우저 저장 데이터를 삭제하면 보관한 계획도 삭제될 수 있습니다.
