### 10주차 개발 목표

9주차에서 구현한 발표 훈련 계획 생성, 저장, 조회 및 취소 기능을 기반으로 사용자 편의성과 화면 탐색 기능을 개선
특히 반응형 내비게이션과 훈련 계획 상태별 필터링을 구현하여 모바일 환경에서도 편리하게 이용하고 저장된 계획을 효율적으로 관리.

| 계획 취소 | 계획 취소 기능 | 취소 상태 표시 및 취소 되돌리기 |
| 계획 개수 | 전체 계획 개수 표시 | 현재 필터에 해당하는 계획 개수 표시 |

###  주요 구현 기능

- 화면 너비가 600px 이하일 때 메뉴 열기 버튼을 표시
- 메뉴 버튼 클릭 시 내비게이션을 열거나 닫는다.
- 메뉴 상태에 따라 버튼 문구를 변경
- `aria-expanded` 속성을 이용해 메뉴의 열림 상태를 전달
- 메뉴 항목을 선택하면 모바일 메뉴가 자동으로 닫힌다.
- 현재 URL의 해시(Hash)를 확인
- 선택된 메뉴에 `is-current` 클래스를 적용
- 현재 메뉴를 색상과 배경으로 강조
- `aria-current="page"` 속성으로 활성 메뉴를 구분

#### 훈련 계획 필터링

내 훈련 계획 영역에 다음 세 가지 필터 버튼을 추가

1. **전체:** 저장된 모든 계획 표시
2. **저장됨:** 취소하지 않은 계획만 표시
3. **취소됨:** 취소 상태인 계획만 표시

필터 버튼을 클릭하면 `currentFilter` 변수가 변경되며, `getVisiblePlans()` 함수에서 해당 조건에 맞는 계획을 반환
`renderPlans()` 함수는 필터링 결과를 이용해 목록을 다시 표시

####. 필터 선택 상태 표시

- 현재 선택한 필터에 `is-active` 클래스를 적용한.
- 선택한 버튼의 색상을 변경
- `aria-pressed` 속성을 이용해 버튼 선택 상태를 표시
- 필터 변경 시 화면을 새로고침하지 않고 목록을 갱신

#### 계획 취소 및 복원

- 저장된 계획에서 '계획 취소하기' 버튼을 클릭하면 취소 상태로 변경
- 취소된 계획에는 '취소됨' 상태를 표시
- 취소된 계획에서는 '취소 되돌리기' 버튼을 제공
- 취소를 되돌리면 다시 '저장됨' 상태로 변경
- 변경된 상태는 로컬 스토리지(Local Storage)에 저장
계획을 취소하더라도 데이터를 즉시 삭제하지 않으므로 나중에 복원

#### 필터별 계획 개수 및 빈 목록 안내

- 선택한 필터에 해당하는 계획 개수를 표시
- 해당 상태의 계획이 없으면 별도의 안내 메시지를 제공
- 전체 목록이 비어 있을 때는 계획 생성 버튼을 표시
- 상태별 필터 결과가 비어 있을 때는 다른 필터를 선택하도록 안내

### 사용자의 흐름

1. 사용자가 Re:hear 웹사이트에 접속
2. 발표 제목과 발표자 이름을 입력.
3. 발표 시간과 질의응답 조건을 선택.
4. 설정 내용을 확인하고 훈련 계획을 저장
5. '내 계획' 영역에서 저장한 계획을 확인.
6. 전체·저장됨·취소됨 중 원하는 필터를 선택한
8. 계획을 취소하거나 취소된 계획을 복원
9. 모바일 환경에서는 메뉴 버튼을 이용해 화면을 이동

### 주요 JavaScript 구현 내용

 `menuToggle` | 모바일 메뉴 버튼 선택 
 `mainNav` | 내비게이션 요소 선택 
 `updateCurrentNav()` | 현재 메뉴 활성화 상태 갱신 
 `filterButtons` | 필터 버튼 목록 선택 
 `currentFilter` | 현재 선택된 필터 저장 
 `getVisiblePlans()` | 필터 조건에 맞는 계획 반환 
 `renderPlans()` | 계획 목록과 개수 갱신 
 `savePlans()` | 계획 상태를 로컬 스토리지에 저장 

### 사용 기술

- HTML5: 웹페이지 구조 및 시맨틱 요소
- CSS3: 반응형 레이아웃 및 선택 상태 스타일
- JavaScript: 이벤트 처리와 동적 화면 제어
- DOM(Document Object Model): 메뉴와 계획 목록 조작
- Local Storage: 훈련 계획 및 취소 상태 저장
- ARIA(Accessible Rich Internet Applications): 접근성 상태 속성 적용
- Git / GitHub: 주차별 소스코드 버전 관리
- GitHub Pages: 정적 웹사이트 배포

### 결과

10주차에서는 기존 발표 훈련 계획 관리 기능을 유지하면서 모바일 메뉴와 상태별 필터 기능을 추가
사용자는 전체 계획 중 원하는 상태의 계획만 선택해 확인할 수 있으며, 취소한 계획을 다시 복원 가능
